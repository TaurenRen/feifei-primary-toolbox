# 狒狒的小学工具箱 · feifei-primary-toolbox

给家长用的、辅导小学生学习的小工具合集。全部是**单文件 HTML**，不联网、不登录、不装软件，双击就能用。每个工具解决一个具体的小麻烦，做完就往里放一个。

## 目前收录

| 工具 | 解决什么 | 文件 |
|---|---|---|
| 听写播报器 | 家长每天给孩子报听写，念到口干舌燥还会漏词、读错音 | [`tools/dictation.html`](tools/dictation.html) |

## 听写播报器怎么用

1. 下载 `tools/dictation.html`，双击用 Chrome / Edge 打开（手机也能开，微信内置浏览器声音容易失效）。
2. 把课本这一课的生词粘进「词语表」，一行一个。换课文直接全选替换。
3. 设间隔（10–60 秒，默认 40）、每个词念几遍（1–3 遍，默认 2 遍）、语速（慢 / 正常偏慢 / 正常）。
4. 点「开始播报」，它自己念，你可以去洗菜。

它有的东西：

- 每个词念完自动倒数，屏幕上直接显示「下一个：还有 N 秒」，孩子知道还有多久
- 上一个 / 再念一遍 / 下一个，写错了当场补读，不用重头来
- 遮住屏幕上的字：只听不看，防抄
- 打乱顺序：防背词序
- 进度条 + 百分比，知道还剩多少个
- 词表存本地，关掉页面下次还在
- 语音下拉里自动列出系统里的中文语音（Windows 一般有 Huihui / Kangkang / Yaoyao）

## 怎么加新工具

一个工具一个 HTML，放进 `tools/`，在 `index.html` 里加一张卡片。不需要构建，不需要依赖，不需要 CDN。这条约束是有意的：家长拿到的是能直接双击的文件，不是需要 `npm install` 的项目。
